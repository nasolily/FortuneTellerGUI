## 📖 About

**Fortune Teller GUI** is a Java desktop application built with **Java Swing** to explore graphical user interface development and event-driven programming.

Inspired by a paper fortune teller, this application lets users click **"Read My Fortune"** to reveal a randomly selected fortune. The project combines simple desktop development with a lighthearted user experience.

---

## ✨ Features

🔮 Reveal a randomly selected fortune

🖼️ Paper fortune teller illustration

⚡ Event-driven interactions

🎲 A collection of fun and silly fortunes

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/nasolily/FortuneTellerGUI
cd FortuneTellerGUI
```

### Open the project

Open the project in **IntelliJ IDEA** and make sure a Java Development Kit (JDK) is installed.

### Run the application

Run the main Java class to begin reading fortunes!
